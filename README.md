# CTA Automated Ticketing System

This repository contains a Python console application for an automated ticketing system developed for the Centrala Transport Authority (CTA) as part of my task 2 – Programming and Scripting.

## Overview
The system:
- Displays underground zones and stations
- Allows users to select boarding and destination zones
- Collects traveller details
- Calculates fares based on zones travelled
- Generates a detailed travel voucher with date and time

## Requirements
- Python 3.11 or later

## Run the Program
To run the application:

```bash
python cta_ticketing.py
